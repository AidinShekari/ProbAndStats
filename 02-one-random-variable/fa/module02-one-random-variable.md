## 2.1 مقدمه: چرا متغیرهای تصادفی؟

### مسئله

در ماژول 1 با رویدادها کار کردیم — زیرمجموعه‌هایی از یک فضای نمونه. اما تحلیل مهندسی به **اعداد** نیاز دارد:

- چه مقدار ولتاژ نویز وجود دارد؟
- چند بسته رسید؟
- توان سیگنال دریافتی چقدر است؟

یک **متغیر تصادفی** خروجی‌های یک آزمایش تصادفی را به اعداد حقیقی نگاشت می‌کند و به این ترتیب امکان استفاده از تمام ابزارهای حساب دیفرانسیل و انتگرال و جبر را برای ما فراهم می‌کند.

### انگیزه مهندسی

| می‌خواهیم تحلیل کنیم... | یک متغیر تصادفی تعریف می‌کنیم... |
|----------------------|-------------------------------|
| نویز در یک مدار | X = ولتاژ نویز (ولت) |
| خطاهای بیت در یک فریم | N = تعداد خطاهای بیت |
| عمر قطعه | T = زمان تا خرابی (ساعت) |
| دامنه سیگنال | A = دامنه دریافتی (V) |
| تأخیر بسته | D = تأخیر سرتاسری (ms) |

## 2.2 تعریف متغیر تصادفی

### تعریف صوری

یک **متغیر تصادفی** X تابعی است که هر خروجی ω در فضای نمونه S را به یک عدد حقیقی نگاشت می‌کند:

$$X: S \rightarrow \mathbb{R}$$
$$\omega \mapsto X(\omega)$$

### تفسیر

متغیر تصادفی به هر خروجی ممکن آزمایش یک مقدار عددی نسبت می‌دهد. تصادفی‌بودن از این ناشی می‌شود که کدام خروجی ω رخ می‌دهد — به‌محض تعیین ω، مقدار X(ω) یک عدد معیّن است.

### مثال مهندسی

**آزمایش:** ارسال 5 بیت روی یک کانال نویزی.
**فضای نمونه:** S = تمام دنباله‌های ممکن درست/خطا برای 5 بیت (2⁵ = 32 خروجی)
**متغیر تصادفی:** X = تعداد خطاهای بیت

| خروجی ω | X(ω) |
|-----------|------|
| (C,C,C,C,C) | 0 |
| (E,C,C,C,C) | 1 |
| (E,E,C,C,C) | 2 |
| ... | ... |
| (E,E,E,E,E) | 5 |

حالا به‌جای کار با 32 خروجی، با یک عدد منفرد X ∈ {0,1,2,3,4,5} کار می‌کنیم.

## 2.3 متغیرهای تصادفی گسسته

### تعریف

متغیر تصادفی X **گسسته** است اگر مقادیر خود را از یک مجموعه **شمارا** (متناهی یا شمارای نامتناهی) بگیرد.

### ویژگی‌ها
- مقادیر را می‌توان فهرست کرد: {x₁, x₂, x₃, ...}
- هر مقدار یک احتمال مشخص دارد (یک «جرم» از احتمال)
- مجموع تمام احتمال‌ها = 1

### مثال‌های مهندسی

| متغیر تصادفی | مقادیر ممکن | زمینه |
|----------------|-----------------|---------|
| تعداد خطاهای بیت | {0, 1, 2, ..., n} | انتقال بسته |
| تعداد ارسال‌های مجدد | {0, 1, 2, ...} | پروتکل ARQ |
| سطح ولتاژ کوانتیزه‌شده | {0, 1, ..., 2ᴺ-1} | خروجی مبدل آنالوگ به دیجیتال N-بیتی |
| تعداد ورودها در هر ثانیه | {0, 1, 2, ...} | ترافیک شبکه |
| تعداد تراشه‌های معیوب | {0, 1, ..., n} | آزمون ویفر |

---

## 2.4 متغیرهای تصادفی پیوسته

### تعریف

متغیر تصادفی X **پیوسته** است اگر مقادیر خود را از یک مجموعه **ناشمارا** (بازه‌ای از اعداد حقیقی) بگیرد.

### ویژگی‌ها
- X می‌تواند هر مقدار در یک محدوده را اختیار کند (مثلاً [0, ∞) یا (-∞, ∞))
- احتمال هر مقدار دقیق منفرد صفر است: P(X = x) = 0
- احتمال‌ها برای بازه‌ها تعریف می‌شوند: P(a ≤ X ≤ b)

### مثال‌های مهندسی

| متغیر تصادفی | محدوده | زمینه |
|----------------|-------|---------|
| ولتاژ نویز حرارتی | (-∞, ∞) | نویز مدار |
| زمان تا خرابی | [0, ∞) | قابلیت اطمینان |
| فاز سیگنال دریافتی | [0, 2π) | مخابرات |
| مقدار مقاومت | (R₀ - δ, R₀ + δ) | ساخت و تولید |
| بهره کانال | [0, ∞) | محوشدگی بی‌سیم |

### چرا برای متغیرهای تصادفی پیوسته P(X = x) = 0 است

تصور کنید یک ولتاژ را اندازه‌گیری می‌کنید. احتمال این‌که V دقیقاً 3.14159265... ولت باشد (با دقت نامتناهی) صفر است. تنها می‌توانیم درباره بازه‌ها بپرسیم: P(3.14 < V < 3.15).

## 2.5 تابع جرم احتمال (PMF)

### تعریف

برای یک متغیر تصادفی گسسته X، **تابع جرم احتمال** عبارت است از:

$$p_X(x) = P(X = x)$$

### ویژگی‌ها

1. **نامنفی بودن:** p_X(x) ≥ 0 برای تمام x
2. **نرمال‌سازی:** Σ p_X(xᵢ) = 1 (جمع روی تمام مقادیر ممکن)
3. **محاسبه احتمال:** P(X ∈ A) = Σ_{x∈A} p_X(x)

### مصورسازی

PMF به‌صورت **خطوط عمودی** (ضربه‌ها) در هر مقدار ممکن نمایش داده می‌شود، که ارتفاع آن برابر با احتمال است.

```{.figure #m02-pmf-stems}
p_X(x)
  |
0.4|     |
  |     |
0.3|  |  |
  |  |  |
0.2|  |  |  |
  |  |  |  |
0.1|  |  |  |  |
  |  |  |  |  |
  +--+--+--+--+--→ x
     0  1  2  3  4
```

### مثال مهندسی: خطاهای بیت در یک بایت

8 بیت ارسال می‌شود که هر بیت احتمال خطای مستقل p = 0.1 دارد.
X = تعداد خطاهای بیت.

p_X(k) = C(8,k) · (0.1)^k · (0.9)^(8-k), for k = 0, 1, ..., 8

| k | p_X(k) |
|---|--------|
| 0 | 0.4305 |
| 1 | 0.3826 |
| 2 | 0.1488 |
| 3 | 0.0331 |
| 4 | 0.0046 |
| 5+ | < 0.001 |

## 2.6 تابع چگالی احتمال (PDF)

### تعریف

برای یک متغیر تصادفی پیوسته X، **تابع چگالی احتمال** f_X(x) به‌گونه‌ای تعریف می‌شود که:

$$P(a \leq X \leq b) = \int_a^b f_X(x) \, dx$$

### ویژگی‌ها

1. **نامنفی بودن:** f_X(x) ≥ 0 برای تمام x
2. **نرمال‌سازی:** ∫_{-∞}^{∞} f_X(x) dx = 1
3. **احتمال = مساحت زیر منحنی** میان دو نقطه

### نکته حیاتی: f_X(x) یک احتمال نیست!

> ⚠️ f_X(x) می‌تواند بزرگ‌تر از 1 باشد!

PDF **چگالی** احتمال را می‌دهد — احتمال در واحد طول. تنها **انتگرال** (مساحت) احتمال را می‌دهد.

**قیاس:** چگالی جرم (kg/m³) جرم نیست. برای به‌دست‌آوردن جرم باید چگالی را روی حجم انتگرال بگیرید. به‌همین‌ترتیب، چگالی احتمال هم احتمال نیست — برای به‌دست‌آوردن احتمال باید روی یک بازه انتگرال بگیرید.

### مصورسازی

```{.figure #m02-pdf-area}
f_X(x)
  |
  |      ╭────╮
  |     ╱ ░░░░ ╲        ← Shaded area = P(a ≤ X ≤ b)
  |    ╱ ░░░░░░ ╲
  |   ╱ ░░░░░░░░ ╲
  |──╱───░░░░░░░░──╲──→ x
  |      a      b
  Total area under curve = 1
```

### مثال مهندسی: ولتاژ نویز حرارتی

ولتاژ نویز حرارتی در یک مدار اغلب از توزیع گاوسی پیروی می‌کند:

$$f_X(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-x^2/(2\sigma^2)}$$

که در آن σ ولتاژ مؤثر (RMS) نویز است.

P(noise exceeds 2σ) = P(|X| > 2σ) = 1 - P(-2σ ≤ X ≤ 2σ) ≈ 1 - 0.9545 = 0.0455

## 2.7 تابع توزیع تجمعی (CDF)

### تعریف

برای هر متغیر تصادفی X (گسسته یا پیوسته)، **تابع توزیع تجمعی** عبارت است از:

$$F_X(x) = P(X \leq x)$$

### ویژگی‌ها

1. **نامنزولی:** اگر a < b، آنگاه F_X(a) ≤ F_X(b)
2. **حدود:** F_X(-∞) = 0، F_X(+∞) = 1
3. **پیوستگی از راست:** F_X(x) از سمت راست پیوسته است
4. **احتمال یک بازه:** P(a < X ≤ b) = F_X(b) - F_X(a)

### CDF برای متغیرهای تصادفی گسسته

CDF یک **تابع پله‌ای** با جهش‌هایی در هر مقدار ممکن است:

```{.figure #m02-cdf-discrete}
F_X(x)
  |
1.0|                          ──────────
  |                    ○─────┘
0.8|              ○────┘
  |         ○───┘
0.4|    ○───┘
  |────┘
0.0|
  +----+----+----+----+---→ x
       0    1    2    3
```

جهش در x = k دارای ارتفاع p_X(k) است.

### CDF برای متغیرهای تصادفی پیوسته

CDF یک منحنی **هموار و پیوسته** است:

$$F_X(x) = \int_{-\infty}^{x} f_X(t) \, dt$$

و برعکس:
$$f_X(x) = \frac{dF_X(x)}{dx}$$

```{.figure #m02-cdf-continuous}
F_X(x)
  |
1.0|                         ___________
  |                    ╱
  |                 ╱
0.5|             ╱
  |          ╱
  |       ╱
0.0|______╱
  +---+---+---+---+---+---→ x
```

### رابطه: PDF ↔ CDF

| جهت | فرمول | معنا |
|-----------|---------|---------|
| PDF → CDF | F_X(x) = ∫_{-∞}^x f_X(t)dt | انتگرال‌گیری از چگالی برای به‌دست‌آوردن احتمال تجمعی |
| CDF → PDF | f_X(x) = dF_X/dx | مشتق‌گیری از CDF برای به‌دست‌آوردن چگالی |

## 2.8 تمایز کلیدی: جرم در برابر چگالی در برابر تجمعی

این یکی از مهم‌ترین تمایزهای مفهومی در نظریه احتمال است.

### جدول مقایسه

| ویژگی | PMF p_X(x) | PDF f_X(x) | CDF F_X(x) |
|----------|-----------|-----------|-----------|
| **برای** | فقط متغیرهای تصادفی گسسته | فقط متغیرهای تصادفی پیوسته | هر دو |
| **مستقیماً می‌دهد** | P(X = x) | چگالی احتمال در x | P(X ≤ x) |
| **دامنه مقادیر** | [0, 1] | [0, ∞) — می‌تواند از 1 فراتر رود! | [0, 1] |
| **جمع/انتگرال** | Σ p_X(x) = 1 | ∫ f_X(x)dx = 1 | از 0 شروع و به 1 ختم می‌شود |
| **به‌دست‌آوردن احتمال** | P(X=x) = p_X(x) | P(a≤X≤b) = ∫ f_X(x)dx | P(a<X≤b) = F(b)-F(a) |

### قیاس بصری: انبار

احتمال را به‌عنوان «ماده‌ای» تصور کنید که روی مقادیر ممکن توزیع شده است:

**گسسته (PMF):** مانند انبار کردن ماده در جعبه‌های شماره‌گذاری‌شده. هر جعبه یک جرم مشخص دارد. PMF جرم هر جعبه را به شما می‌گوید.

```{.figure #m02-pmf-boxes}
    ┌───┐
    │0.4│ ┌───┐
    │   │ │0.3│ ┌───┐
    │   │ │   │ │0.2│ ┌───┐
    └───┘ └───┘ └───┘ └───┘
     x=0   x=1   x=2   x=3
     
    Total mass in all boxes = 1
```

**پیوسته (PDF):** مانند پهن‌کردن ماده در طول یک قفسه پیوسته. چگالی به شما می‌گوید ماده در هر نقطه چقدر ضخیم است. جرم را با محاسبه مساحت (ضخامت × عرض) به دست می‌آورید.

```{.figure #m02-pdf-area-12}
         ╭────────╮
        ╱          ╲
       ╱     ░░░░    ╲      ← Area of shaded region = P(1 ≤ X ≤ 2)
      ╱     ░░░░░░    ╲
    ─╱──────░░░░░░░░────╲──
          1      2

    Total area under curve = 1
```

**تجمعی (CDF):** مانند یک جمع در حال اجرا — تا این نقطه چه مقدار ماده انباشته‌اید؟

### چرا این موضوع در مهندسی اهمیت دارد

**مثال:** یک ولتاژ نویز X دارای PDF f_X(x) = 2 برای x ∈ [0, 0.5] است.

- f_X(0.3) = 2 — این یک احتمال نیست! به این معناست که چگالی برابر 2 V⁻¹ است.
- P(0.2 ≤ X ≤ 0.4) = ∫_{0.2}^{0.4} 2 dx = 2 × 0.2 = 0.4 — این یک احتمال است.
- P(X = 0.3) = 0 — برای متغیرهای تصادفی پیوسته، یک نقطه منفرد احتمال صفر دارد.

### خطاهای رایجی که باید از آن‌ها پرهیز کرد

| ❌ گزاره نادرست | ✅ گزاره درست |
|---|---|
| «احتمال در x=2 برابر f(2) است» | «چگالی احتمال در x=2 برابر f(2) است» |
| «f(x) باید ≤ 1 باشد» | «f(x) می‌تواند هر مقدار نامنفی باشد» |
| «برای X پیوسته P(X=3) = f(3)» | «برای X پیوسته P(X=3) = 0» |
| «PMF و PDF یک چیز هستند» | «PMF جرم می‌دهد؛ PDF چگالی می‌دهد» |

## 2.9 تبدیل‌های متغیرهای تصادفی

### انگیزه

در مهندسی، اغلب توزیع یک کمیت را می‌دانیم اما توزیع **تابعی** از آن کمیت را نیاز داریم:

- ولتاژ V معلوم است → توان P = V²/R لازم است
- سیگنال خطی X معلوم است → مقدار dB یعنی Y = 10·log₁₀(X) لازم است
- نویز N معلوم است → |N| (نویز یکسوسازی‌شده) لازم است

### بیان مسئله

داده شده: X با PDF معلوم f_X(x) یا PMF معلوم p_X(x)
مطلوب: توزیع Y = g(X)

### حالت 1: تبدیل متغیر تصادفی گسسته

اگر X گسسته با PMF p_X(x) باشد و Y = g(X):

$$p_Y(y) = \sum_{x: g(x)=y} p_X(x)$$

احتمال‌های تمام مقادیر x را که به همان y نگاشت می‌شوند جمع کنید.

**مثال:** X ∈ {-2, -1, 0, 1, 2} با احتمال برابر 0.2 برای هر یک.
Y = X²

| Y = X² | مقادیر X که به Y نگاشت می‌شوند | p_Y(y) |
|---------|----------------------|---------|
| 0 | {0} | 0.2 |
| 1 | {-1, 1} | 0.4 |
| 4 | {-2, 2} | 0.4 |

### حالت 2: تبدیل یکنوا (پیوسته)

اگر Y = g(X) که در آن g اکیداً یکنوا و مشتق‌پذیر است:

$$f_Y(y) = f_X(g^{-1}(y)) \cdot \left|\frac{dg^{-1}(y)}{dy}\right|$$

یا به‌طور معادل:
$$f_Y(y) = \frac{f_X(x)}{|g'(x)|}\bigg|_{x=g^{-1}(y)}$$

**استخراج از طریق روش CDF:**
1. با CDF شروع کنید: F_Y(y) = P(Y ≤ y) = P(g(X) ≤ y)
2. وارون کنید: = P(X ≤ g⁻¹(y)) اگر g صعودی باشد
3. مشتق بگیرید: f_Y(y) = f_X(g⁻¹(y)) · d/dy[g⁻¹(y)]

### حالت 3: تبدیل غیریکنوا

اگر g یکنوا نباشد، دامنه را به بازه‌هایی تقسیم کنید که در آن‌ها g یکنوا است:

$$f_Y(y) = \sum_i \frac{f_X(x_i)}{|g'(x_i)|}$$

که در آن x₁, x₂, ... همگی جواب‌های g(x) = y هستند.

### مثال مهندسی: توان از ولتاژ

یک ولتاژ نویز X دارای PDF f_X(x) است (مثلاً گاوسی با میانگین صفر).
توان تلف‌شده در یک مقاومت 1Ω: P = X²

از آنجا که Y = X² یکنوا نیست (هر دو +x و -x همان y را می‌دهند):

برای y > 0: هر دو x = +√y و x = -√y جواب هستند.
g(x) = x²، پس g'(x) = 2x

$$f_Y(y) = \frac{f_X(\sqrt{y})}{2\sqrt{y}} + \frac{f_X(-\sqrt{y})}{2\sqrt{y}}, \quad y > 0$$

اگر X گاوسی با میانگین صفر باشد: f_X(x) = f_X(-x)، پس:
$$f_Y(y) = \frac{f_X(\sqrt{y})}{\sqrt{y}}, \quad y > 0$$

### مثال مهندسی: تقویت خطی

سیگنال Y = aX + b (تقویت‌کننده با بهره a و آفست b).
X دارای PDF f_X(x) است.

g⁻¹(y) = (y-b)/a، و |d/dy[(y-b)/a]| = 1/|a|

$$f_Y(y) = \frac{1}{|a|} f_X\left(\frac{y-b}{a}\right)$$

## 2.10 مثال‌های MATLAB

### مثال 1: رسم یک PMF

```matlab
%% PMF of Number of Bit Errors in a Byte
n = 8;           % bits per byte
p = 0.1;         % bit error probability
k = 0:n;         % possible values

% Compute PMF (binomial distribution)
pmf = binopdf(k, n, p);

% Plot
figure;
stem(k, pmf, 'filled', 'LineWidth', 2);
xlabel('Number of Errors (k)');
ylabel('P(X = k)');
title('PMF: Bit Errors in 8-bit Byte (p = 0.1)');
grid on;

% Verify normalization
fprintf('Sum of PMF = %.6f (should be 1)\n', sum(pmf));
```

### مثال 2: رسم یک PDF و بررسی ویژگی‌ها

```matlab
%% PDF of Gaussian Noise Voltage
sigma = 0.5;     % RMS noise voltage
x = linspace(-3*sigma, 3*sigma, 1000);

% Compute PDF
pdf_x = normpdf(x, 0, sigma);

% Plot
figure;
plot(x, pdf_x, 'b-', 'LineWidth', 2);
xlabel('Voltage (V)');
ylabel('f_X(x) [V^{-1}]');
title('PDF: Gaussian Noise (σ = 0.5 V)');
grid on;

% Verify normalization (numerical integration)
dx = x(2) - x(1);
total_area = trapz(x, pdf_x);
fprintf('Total area under PDF = %.6f (should be 1)\n', total_area);

% Note: PDF values can exceed 1!
fprintf('Maximum PDF value = %.4f (can be > 1!)\n', max(pdf_x));

% Compute P(|X| > 1V)
prob_exceed = 1 - normcdf(1, 0, sigma) + normcdf(-1, 0, sigma);
fprintf('P(|X| > 1V) = %.4f\n', prob_exceed);
```

### مثال 4: تبدیل یک متغیر تصادفی

```matlab
%% Transformation: Power from Noise Voltage
% X = noise voltage, Gaussian(0, sigma)

sigma = 1;

X = sigma * randn(1, N);

hold on;

plot(x_theory, normpdf(x_theory, 0, sigma), 'r-', 'LineWidth', 2);

subplot(2,1,2);
```

### مسئله 2: ویژگی‌های PMF
یک متغیر تصادفی X دارای PMF زیر است: p_X(0) = 0.1، p_X(1) = 0.3، p_X(2) = c، p_X(3) = 0.2.

(a) مقدار c را بیابید.
(b) P(X ≥ 2) را بیابید.
(c) F_X(1.5) را بیابید.
(d) P(0.5 < X ≤ 2.5) را بیابید.

**حل:**
(a) مجموع = 1: 0.1 + 0.3 + c + 0.2 = 1 → c = 0.4

(b) P(X ≥ 2) = p_X(2) + p_X(3) = 0.4 + 0.2 = 0.6

(c) F_X(1.5) = P(X ≤ 1.5) = p_X(0) + p_X(1) = 0.1 + 0.3 = 0.4

(d) P(0.5 < X ≤ 2.5) = p_X(1) + p_X(2) = 0.3 + 0.4 = 0.7

---

### مسئله 3: PDF و CDF
یک متغیر تصادفی دارای PDF زیر است:
f_X(x) = cx برای 0 ≤ x ≤ 4، و در غیر این صورت 0.

(a) مقدار c را بیابید.
(b) تابع CDF یعنی F_X(x) را بیابید.
(c) P(1 ≤ X ≤ 3) را بیابید.
(d) مقدار x₀ را بیابید که در آن P(X ≤ x₀) = 0.5.

**حل:**
(a) ∫₀⁴ cx dx = c·[x²/2]₀⁴ = c·8 = 1 → c = 1/8

(b) F_X(x) = ∫₀ˣ (t/8)dt = x²/16، برای 0 ≤ x ≤ 4
    F_X(x) = 0 برای x < 0؛ F_X(x) = 1 برای x > 4

(c) P(1 ≤ X ≤ 3) = F_X(3) - F_X(1) = 9/16 - 1/16 = 8/16 = 0.5

(d) x₀²/16 = 0.5 → x₀² = 8 → x₀ = 2√2 ≈ 2.83

### مسئله 4: تبدیل
یک حسگر دما X را اندازه‌گیری می‌کند که به‌طور یکنواخت روی [20, 30] °C توزیع شده است.
ولتاژ خروجی Y = 0.1X - 2 است (حسگر خطی).

(a) PDF مربوط به Y را بیابید.
(b) محدوده Y را بیابید.
(c) P(Y > 0.5) را بیابید.

**حل:**
(a) X ~ Uniform[20, 30]، پس f_X(x) = 1/10 برای 20 ≤ x ≤ 30.
Y = 0.1X - 2، پس a = 0.1 و b = -2.
f_Y(y) = (1/|a|) · f_X((y-b)/a) = (1/0.1) · (1/10) = 1 برای محدوده معتبر.

(b) وقتی X = 20: Y = 0.1(20) - 2 = 0؛ وقتی X = 30: Y = 0.1(30) - 2 = 1
محدوده Y: [0, 1]. پس Y ~ Uniform[0, 1].

(c) P(Y > 0.5) = 1 - F_Y(0.5) = 1 - 0.5 = 0.5

---

### مسئله 5: تبدیل غیریکنوا
یک ولتاژ X ~ Uniform[-1, 1] V. توان لحظه‌ای Y = X² است.

(a) CDF مربوط به Y را بیابید.
(b) PDF مربوط به Y را بیابید.
(c) با شبیه‌سازی MATLAB بررسی کنید.

**حل:**
(a) برای 0 ≤ y ≤ 1:
F_Y(y) = P(X² ≤ y) = P(-√y ≤ X ≤ √y) = F_X(√y) - F_X(-√y)

از آنجا که X ~ Uniform[-1,1]: F_X(x) = (x+1)/2

F_Y(y) = (√y + 1)/2 - (-√y + 1)/2 = √y

(b) f_Y(y) = dF_Y/dy = 1/(2√y) برای 0 < y ≤ 1

(c) MATLAB:
```matlab
N = 100000;
X = 2*rand(1,N) - 1;   % Uniform[-1,1]
Y = X.^2;
histogram(Y, 100, 'Normalization', 'pdf');
hold on;
y = linspace(0.01, 1, 200);
plot(y, 1./(2*sqrt(y)), 'r-', 'LineWidth', 2);
legend('Empirical', 'Theory: 1/(2√y)');
xlabel('Y = X²'); ylabel('f_Y(y)');
```

## 2.12 نکات کلیدی

1. **متغیرهای تصادفی** خروجی‌های آزمایش را به اعداد برای تحلیل ریاضی تبدیل می‌کنند
2. **PMF** احتمال واقعی را برای متغیرهای تصادفی گسسته می‌دهد (ارتفاع میله‌ها جمعاً 1 می‌شود)
3. **PDF** چگالی احتمال را برای متغیرهای تصادفی پیوسته می‌دهد (مساحت احتمال را می‌دهد، نه ارتفاع)
4. **CDF** به‌طور کلی کار می‌کند — احتمال تجمعی P(X ≤ x) را می‌دهد
5. **تبدیل‌ها** به ما امکان می‌دهند توزیع توابعی از متغیرهای تصادفی را استخراج کنیم
6. **روش CDF** (نخست CDF را بیابید، سپس مشتق بگیرید) اغلب ایمن‌ترین رویکرد برای تبدیل‌ها است
